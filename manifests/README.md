# manifests/

Generated by the tooling, don't hand-edit. Each approved submission lands here as `manifests/<author>/<repo>/<version>.json` (the full, immutable manifest for that release), next to `latest.json` and `latest.<major>.json` pointers.

See [../docs/SUBMITTING.md](../docs/SUBMITTING.md) to submit a mod and [../docs/REPO_STRUCTURE.md](../docs/REPO_STRUCTURE.md) for the schema.
